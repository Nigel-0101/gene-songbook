# 简 Gene · 听海拾音

暗海光球特写从上方落到标题位置，镜头随后后退，展示珊瑚与双向鱼群。继续滚动，横向鱼群、小水母与海龟游过，人物场景从右向左柔和显露，再穿过珊瑚来到海底乐库。古书由琴架浮近，封面绕书脊翻开；人物卡牌书签独立于真实双页，曲面翻页保留纸面内容。

旧纸、不规则缺口、纸层厚度、曲面明暗与书签旧纸尾牌共同构成阅读场景。823 首歌曲，按可用高度自适应每页容量。支持搜索、收藏、最近、随机、前后翻页和跳页。点歌只复制文字，不向直播平台发送消息；收藏和最近记录仅保存在当前浏览器。

桌面支持完整动效及静态浏览。手机直接显示个人介绍与四个社交入口，随后是一张连续歌单；淡化的无框人物插画叠在纸页中央，不显示独立书签，也无需经过开场和翻书动画。系统减少动态效果可跳过动画。B 站和抖音主页、直播间均为外链。

官方头像用于对应创作者展示。人物卡牌和场景等插画为本项目根据用户确认方向生成的素材，并非声称取得官方立绘原文件；原图未虚报放大分辨率。字体授权见 fonts、fonts-handwritten。无后台、无凭据和内部研究记录。
