# 简 Gene · 听海拾音

桌面保留光球特写落下的开场、海底场景与古书翻开动效。歌单以旧纸双页呈现，独立人物书签采用用户提供的原立绘，搭配连续边框及紧凑的主页、直播间入口。

手机直接显示个人介绍与四个社交入口，随后是一张连续歌单。原立绘淡化叠在歌单中央，文字为“简 Gene”，不显示铭牌框、独立书签或翻书开场。个人介绍页已移除“打开拾音册”按钮，可使用导航或继续滚动进入歌单。

823 首歌曲；支持搜索、收藏、最近、随机、翻页和跳页。点歌只复制文字，不向直播平台发送消息；收藏和最近记录仅保存在当前浏览器。B 站和抖音主页、直播间均为外链。桌面支持静态浏览，并遵循系统减少动态效果设置。

头像及本次人物立绘来自用户提供的对应创作者素材，网站使用网页尺寸导出文件。装饰边框与海底场景为项目创作素材。字体授权见 fonts、fonts-handwritten。无后台、凭据或内部研究记录。

本版同时减少了电脑滚动时不可见画面的重复绘制，并调整舞台定位。偶发闪黑的持续观察仍有必要。
